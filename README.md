# eat_what

網站：https://circleo-o.github.io/eat_what/

## 一、專案概述

一個幫學生解決「今天吃什麼」的轉盤網頁：依時段、預算、料理種類篩選後，轉動夜市招牌風格的轉盤抽出餐點。

| 項目 | 內容 |
| --- | --- |
| 目標使用者 | 常外食、每天為吃什麼煩惱的學生 |
| 使用情境 | 上學前、下課、讀書餓了時，幫助學生做出決定 |
| 使用裝置 | 手機為主，電腦也能使用 |

## 二、功能規格

### F1 轉盤抽選

- 按「開轉！」，轉盤旋轉約 4 秒後減速停下，指針指向的格子就是結果，並跳出結果卡片與紙花動畫。
- 結果卡片顯示餐點、國旗、價格與時段；「就吃這個！」寫入歷史，「再轉一次」不記錄並直接再轉。

### F2 條件篩選

| 條件 | 介面 |
| --- | --- |
| 時段 | 按鈕單選：不限、早餐、正餐、宵夜 |
| 預算（每人） | 拖動拉桿：30 元到「不限」，每格 10 元 |
| 種類 | 國旗按鈕複選：中式、台式小吃、日式、韓式、義式、美式、東南亞 |

轉盤只放符合條件的餐點，最多 12 格，超過時可按「換一批」；少於 2 項時提示「放寬一點吧！」並停用「開轉！」。

### F3 抽籤歷史

- 列出最近 10 筆紀錄，存在瀏覽器 localStorage，重新整理後仍保留。
- 「避開最近吃過的」開關：最近 3 筆的餐點不會出現在轉盤上。
- 「清除紀錄」需再按「確定清除」才會清除。

### F4 餐點資料

內建 48 項餐點，每項有名稱、emoji、時段、一人份普遍價格與料理種類，例如蛋餅 35 元、牛肉麵 170 元、拉麵 280 元。

## 三、畫面配置與操作流程

單頁由上到下為招牌標題、篩選區、轉盤、歷史紀錄；電腦版的篩選區與轉盤左右並排，結果卡片從畫面中央彈出。

1. 選時段、拖動預算、點選國旗，轉盤即時更新。
2. 按「開轉！」，轉盤停下後跳出結果卡片。
3. 按「就吃這個！」記錄下來，或按「再轉一次」重抽。

## 四、視覺風格

夜市招牌的可愛繽紛風：深藍紫夜空背景（`#1E1B4B`），搭配招牌紅、亮黃、粉紅、薄荷綠、天藍五色。

- 招牌標題與轉盤外圈都有發光燈泡，轉動時閃得更快。
- 料理種類用 SVG 國旗表示，因為 Windows 不支援國旗 emoji。
- 圓潤字型、大圓角粗邊框按鈕，抽中時噴彩色紙花。

## 五、技術規格與驗收標準

單一 `index.html`（CSS、JavaScript 內嵌），轉盤用 Canvas 繪製，資料存在 localStorage，支援手機到電腦的響應式畫面，部署在 GitHub Pages。
